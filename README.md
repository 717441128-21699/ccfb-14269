# CELS Studio · 手绘动画线稿分层与上色工具

面向纸质动画生产流程的扫描件处理工具：把扫描进来的动画纸自动**分层**（墨线 / 红铅阴影分界 / 蓝铅高光），
对齐定位孔、切出闭合区域，并支持**按镜头填色、阴影自动提案、中间画色块沿用与跨帧对应**。

技术栈：**TypeScript + WebGL2 + Vite + Vitest**。核心算法是不依赖 DOM 的纯 TS 实现（CPU 参考实现），
WebGL2 着色器在浏览器里承担颜色分层与仿射重采样的加速。

## 三个工作页面

1. **描线分层**：生成测试线稿或导入真实扫描件 → 分层处理，查看墨线/红铅/蓝铅/标签总览各层，
   显示每阶段耗时、压墨恢复像素数、闭合区域数，可导出单层 PNG，可切换 WebGL2 加速。
2. **上色**：按镜头选帧，点击闭合区域填色，一键自动填阴影/高光色，支持手动改判区域类型，
   侧栏显示帧间轨道对应、未动区域沿用情况。
3. **色指定表**：独立管理角色配色（基色/阴影色/高光色三件套），支持导入导出 JSON，
   上色页只引用颜色 id，改色后全帧跟随。

## 核心算法（src/core）

- `holes.ts` 定位孔检测（降采样 + 连通块几何筛选）与**相似变换**配准（三孔共线，完整仿射会奇异）。
- `classify.ts` 颜色分层：色度优先的像素分类 + **多源受限泛洪压墨恢复**，
  解决彩铅压在墨线上那段的归层；纯墨线因离彩铅源远、受短半径约束不会被吞。
- `regions.ts` **游程编码 + 并查集**两遍连通域（内存只与游程数相关，抗扫描噪声碎块），
  形态学闭运算封闭线条接缝，minArea 过滤噪声小洞。
- `shadows.ts` 红/蓝分界线膨胀后切分闭合区域，按邻接关系提案阴影/高光，支持手动改判。
- `tracker.ts` 跨帧色块对应：IoU + 质心漂移贪心匹配，语义记忆保证同色块跨帧复用同一轨道，
  未动区域（高重合 + 无帧差）标记为可直接沿用上一张颜色。
- `pipeline.ts` 串联整条处理链并输出各阶段耗时。

## 合成测试数据（src/synthetic）

三种参数化角色造型——**萌系圆脸（曲线）、机甲硬朗（直线折角）、兽耳 Q 版（头大身小）**，
每帧产出 RGB 扫描图 + 像素级分层真值 + 语义区域真值。噪声模型包含：纸纹、轻失焦模糊、
随机断笔、线条抖动、传感器高斯噪声、椒盐噪声、光照倾斜，以及可控的彩铅压墨段。

## 目录结构

```
src/core/      纯 TS 算法（Node 与浏览器共用，可单测）
src/gl/        WebGL2 引擎（颜色分类/仿射重采样/图层渲染着色器）
src/synthetic/ 参数化造型与扫描噪声生成器
src/ui/        三个工作页面与状态管理
src/io/        PNG 编解码（Node 侧）
test/          分层/压墨/配准/阴影/区域填色/跨帧追踪/性能
scripts/       样例生成脚本
```
